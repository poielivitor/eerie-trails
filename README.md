# Eerie Trails

Por favor, acesse o link do meu jogo atual: https://perseguicao.lovable.app/

Analise o código, a estrutura visual, sons, as mecânicas de movimento e a lógica do jogo exatamente como ele está publicado no link.

Quero que você recrie a estrutura exata desse jogo como base e aplique as seguintes alterações:

o caminho deve ter 250 metros no total.
faça a animação do jogador entrando na cabana, caso ele chegue lá.
faça a lua e as estrelas ficarem paradas, sem movimento.
faça o jogador ter uma visão de 360 graus, conseguindo olhar para cima e para baixo tambem

Quando o jogador tiver andado 75 metros, faça um vulto de uma sombra assustadora passar na frente do jogador, ao mesmo tempo um sussuro fazendo "psiu".

Quando o jogador tiver andado 91 metros, faça um morcego passar voando perto do jogador.

Quando o jogador tiver andado 110 metros, faça uma sobra andando rapido para frente e sumindo no horizonte, passando do lado do jogador. 


Quando o jogador tiver andado 135 metros, faça a vela apagar por 2 segundos e reacender.



Quando o jogador tiver andado 170 metros, faça ecoar um berro de panico e assustador ecoando por 2 segundos.   


Quando o jogador tiver andado 200 metros, faça um esquilo passar na frente do jogador


Quando o jogador tiver andado 220 metros, faça um grito assustador ecoar dizendo "Hey"  

Mantenha toda a jogabilidade e o estilo visual original que já funciona, modificando apenas o que foi solicitado acima.
